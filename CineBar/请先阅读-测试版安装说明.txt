CineBar 0.8.3-test.11 测试版安装说明
测试编号：0.8.3-test.11（Build 27）
适用于：macOS 13 Ventura 及以上

重要提示
--------
这是功能验证用测试版，不是正式发行版。它尚未经过 Apple 公证，也没有上架
Mac App Store。请只使用开发者直接提供的完整 CineBar 测试 ZIP。

一、安装前
1. 如果旧版 CineBar 正在运行，点击菜单栏图标，再点击左下角“退出”。
2. 双击下载的 ZIP 解压，确认里面有 CineBar.app 和安装说明。

二、安装
1. 打开 Finder，进入“应用程序”。
2. 把 CineBar.app 拖进“应用程序”文件夹。
3. 如果系统询问是否替换，确认旧版已退出后选择“替换”。

三、第一次打开
1. 在“应用程序”中找到 CineBar。
2. 按住 Control 键点击 CineBar，选择“打开”。
3. 出现无法验证开发者提示时，再选择“打开”。
4. 启动后请在屏幕顶部菜单栏寻找 CineBar 黑白图标。

如果没有“打开”按钮：
进入“系统设置”→“隐私与安全性”，向下找到 CineBar 被阻止的提示，点击
“仍要打开”，验证 Mac 密码或 Touch ID。不要关闭整个 macOS 安全保护功能。

四、更新
1. Build 27 已发布独立签名的 appcast 与不可变归档，可在 CineBar 的“设置”→“更新”
   中检查、下载并安装；也可直接下载：
   https://cinebar.cc/downloads/CineBar-0.8.3-test-build-27-universal.zip
2. Build 16 用户需要先从
   GitHub Releases 手动安装一次 Sparkle 版本（Build 17 或更新版本）：
   https://github.com/leeugm-create/CineBar/releases
3. 之后的版本可在 CineBar 的“设置”→“更新”中检查、下载并安装。
4. 每个更新包都会用 CineBar 内置的 EdDSA 公钥验证；签名不匹配的包不会安装。
5. 本测试构建仍未经过 Apple 公证。首次安装的 macOS 安全确认与更新签名验证是
   两个不同的步骤。
6. 如果不希望启动时自动检查，在“设置”→“更新”关闭“启动时自动检查”；仍可
   随时点击“立即检查”手动检查。

本地片库
--------
1. 切换到“本地片库”，点击“添加文件夹”，选择包含视频的文件夹并授予 macOS 文件夹访问权限。
2. 点击“刷新”扫描目录；之后放入已选文件夹的新视频会自动加入。电影、电视剧和其他视频按文件名保守分类，自拍、屏幕录制等零碎视频保留在“其他视频”。
3. 内容类型可以与未看、待匹配、不可用等状态组合筛选；从详情返回后仍保留搜索与筛选条件。
4. 已确认的电影或电视剧可打开完整资料页；未匹配文件和其他视频只显示本地文件详情，不显示虚构的外部评分、演员、剧照或预告。
5. TMDB 只提供候选项；电影或电视剧可以手动输入片名搜索，必须“确认匹配”后才更新资料；匹配窗口可随时关闭，旧搜索不会覆盖新结果。
6. 播放只打开本机文件，依次尝试 IINA、VLC 和 macOS 系统默认播放器；断网仍可播放。
7. 移动硬盘未连接、文件被移动或权限失效时，重新连接存储卷，或使用“重新定位文件”。
8. CineBar 不上传本地影片，也不提供下载或盗版资源。

五、首次使用
1. 点击菜单栏图标打开 CineBar。
2. 在设置中选择语言、外观、玻璃背景不透明度、自动隐藏时间和窗口是否可移动。
3. 系统请求通知权限时请选择“允许”，否则提醒无法弹出。
4. 如需开机自动运行，在“设置”→“通用”中开启登录启动。
5. 双屏使用时，请点击目标屏幕顶部的 CineBar 菜单栏图标。
6. 预览使用者不需要域名、Cloudflare、API Key、数据库、社区账号或部署任何
   项目；影片资料、多重评分、社区评分和品牌分享均已配置。
7. “即将上映”的每一行都会显示日期；没有确定日期时显示“上映日期待定”。
8. 日历按钮只对今天或未来的上映日期显示；过去日期不会创建提醒。
9. 演员照片和影片剧照打开大图后，点击右上角“下载”即可选择保存位置。
10. 设置→支持中的“Buy me a coffee”会打开 CineBar 的 PayPal 一次性支持页面。

六、评分
1. 评分范围为 0–10 分，每次调整 0.5 分。
2. 同一台 Mac 的同一安装对每部电影或电视剧只能评分一次。
3. 评分提交后不能修改或删除，请确认后再提交。
4. 成功后评分编辑区域会消失，“我的评分”显示在多重评分末尾。
5. 换电脑、重装系统或清除身份数据可能被识别为新安装。
6. 应用启动时每天最多发送一次匿名安装统计（版本、构建号、macOS 主版本、芯片架构和界面语言）。
   安装编号只用于去重，并在服务端转换为不可逆哈希；不上传影片、文件路径、账号或原始安装编号，
   也不会读取登录钥匙串。测试版不提供关闭开关。

七、分享
1. 一个“分享”按钮会直接打开 macOS 系统分享面板。
2. CineBar 只向系统提交一个网页链接，因此微信等提供兼容原生分享扩展的应用
   可以出现在面板中。“拷贝”项目是没有原生分享扩展时的备用方式。
3. 通过 Chrome 安装的 X 网页应用不会作为 macOS 原生分享服务出现；不保证 X
   或其他所有第三方应用都会出现在系统分享面板中。
4. 电影链接为 /m/编号，电视剧链接为 /t/编号。分享页最多显示六位主要演员，
   并链接到 CineBar 的 GitHub Releases 页面。
5. 影片、社区评分和分享服务使用 cinebar.cc 自定义域名，不依赖旧测试服务域名，
   不要求代理或 VPN。网络暂时异常时会优先显示上次成功加载的真实影片列表。
6. 当前没有香港备用服务器；单一网络测试成功不能代表所有中国大陆运营商。
7. 测试服务维护不会影响本地片单；分享功能不提供非法下载资源。

八、退出和卸载
退出：点击菜单栏图标，再点击面板左下角带电源图标的“退出”。
卸载：退出后，把“应用程序”中的 CineBar 拖到废纸篓。如果开启过登录启动，
可先在程序设置中关闭，或在“系统设置”→“通用”→“登录项”中移除。

九、常见问题
1. 没有菜单栏图标：确认程序正在运行；菜单栏空间不足时先退出其他菜单栏应用。
2. 面板出现在错误屏幕：关闭面板，在目标屏幕顶部重新点击 CineBar 图标。
3. 资料加载失败：检查网络并在详情页点击刷新，稍后再试。
4. 提示程序已损坏：删除该副本，向开发者重新取得完整测试 ZIP。
5. 第一次通过“隐私与安全性”允许未公证测试版时，macOS 可能要求验证 Mac
   密码或 Touch ID；这是系统安全确认，不是 CineBar 的钥匙串密码请求。
6. 本地片库没有影片或文件不可用：确认文件夹访问权限，点击“刷新”；移动磁盘先重新连接，
   文件移动后使用“重新定位文件”。

反馈时请提供 Mac 型号、macOS 版本、CineBar 版本、是否双屏、复现步骤和截图。
请勿在截图中泄露邮箱、API Key 或其他隐私信息。
