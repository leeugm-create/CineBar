# CineBar

一个直接分发的 macOS 菜单栏影片发现原型。

当前测试分支构建为 **0.8.3-test.7（Build 23）**，不代表正式发布版本。
测试安装包必须同时包含 `请先阅读-测试版安装说明.html` 和纯文本备用说明。

## 功能

- 原创应用图标
- 菜单栏使用应用票券图标的自动黑白模板版本
- 菜单栏唤起、固定宽度且仅可纵向拉伸的一体化浮动窗口
- 可选择是否允许自由移动窗口；右下角提供可实际拖动的纵向拉伸手柄
- 15 秒、30 秒、1 分钟、2 分钟、5 分钟或永不自动隐藏
- 每日按电影偏好推荐三部电影，并按电视剧偏好推荐三部电视剧
- 电影和电视剧推荐偏好分开保存在本机
- 可选择登录 Mac 时自动启动
- 跟随系统、白天、夜晚三种外观
- 玻璃背景不透明度可在 50%–100% 调节，默认 85%，不影响文字与海报
- 中文（简体）、繁体中文（香港/台湾）、English (US)、日本語、한국어切换
- macOS 26 及以上使用原生 Liquid Glass，旧系统使用兼容玻璃材质
- 电影依次提供本周热门、每日电影推荐、即将上映分页
- “即将上映”按所选地区的有效上映日期升序排列，并显示日期与星期；没有确定日期时显示“上映日期待定”
- 电视剧依次提供本周热门电视剧、每日电视剧推荐、今日播出分页
- 今日播出列表逐条显示播出日期
- 搜索电影、电视剧或演员，支持单字及模糊搜索，并可一键清除
- 按年份和类型分类选片，结果支持继续分页加载
- 2000 年以前、2000 年至当前年份的精确年份单选
- 年代与电影类型两个单选条件可组合筛选
- 26 类电影类型；TMDB 非原生类型使用关键词检索补充
- TMDB 评分、简介和海报
- 内置 OMDb 多重评分（IMDb、烂番茄影评人分、Metacritic）
- 电影与电视剧均支持 0–10 分、0.5 间隔的匿名 CineBar 共享评分
- 详情页显示 CineBar 平均分、评分人数和本机“我的评分”，且不覆盖 TMDB
- 电影与电视剧均可按国家/地区筛选，推荐偏好也可多选国家/地区
- 国家/地区清单来自 TMDB 官方配置接口，支持搜索与常用地区快捷入口
- 电影与电视剧分别显示地区官方分级卡片及 CineBar 年龄分级卡片
- 影片详情显示演员阵容、角色、照片和全球累计票房
- 详情页内嵌播放官方 YouTube 预告；YouTube 无法访问时提供哔哩哔哩、腾讯视频、优酷、爱奇艺的官方搜索入口
- 预告点击后自动播放，支持内嵌、独立浮窗与全屏三种播放模式
- International、Official Final、Official Teaser 等预告标签随界面语言显示
- 影片资料显示全球首映、语言地区上映日期、片长、制片国家/地区和 IMDb 编号
- 演员照片和影片剧照可点击查看原图，支持关闭及左右浏览
- 图片预览支持通过系统保存面板下载当前照片
- 今天及未来的上映日期可加入 macOS 日历并自动设置提前一天提醒；过去日期不显示入口
- 影片剧照直接在详情页展示并支持刷新
- 片名可选择或通过右键菜单复制
- 电影使用 `/m/<ID>`、电视剧使用 `/t/<ID>` 的永久品牌短链接
- 一个“分享”按钮会直接打开 macOS 系统分享面板
- CineBar 只向系统提交一个网页链接，因此微信等提供兼容原生分享扩展的应用可以
  出现在面板中；系统的“拷贝”项目是没有原生分享扩展时的备用方式
- 通过 Chrome 安装的 X 网页应用不会作为 macOS 原生分享服务出现；不保证 X
  或其他所有第三方应用都会出现在系统分享面板中
- 分享页最多显示六位主要演员，并链接到 CineBar 的 GitHub Releases 页面
- 演员页显示年龄、生卒日期、又名、出生地地图、X、Instagram 和照片
- 演员参演电影与电视剧均可继续进入详情
- 电视剧可按季展开每一集的简介、评分、播出日期和剧照
- 电视剧简介直接展示剧照
- 通过 TVMaze 补充下一集具体播出时间并转换为本地时区
- 单集提醒可选择提前一天或播出当天的具体时间
- 电影和电视剧可通过爱心保存到本机“我的片单”
- 移除会在首次启动出现的空白 SwiftUI 设置场景
- 按地区查询正版观看平台
- 电视剧观看平台可直接点击进入对应平台或正版观看入口
- 用户无需申请或填写 TMDB Token、OMDb API Key
- 匿名评分安装编号保存在 CineBar 本地偏好，不访问登录钥匙串
- TMDB 与 OMDb 通过 CineBar 开发者维护的 Cloudflare 服务安全连接

## 本地片库

- 在“本地片库”选择包含视频文件的文件夹；CineBar 只记录授权文件夹内的本地文件，不上传影片，也不提供下载或盗版片源。
- 点击“刷新”扫描目录；新加入的影片会自动出现。文件名匹配 TMDB 仅提供候选项，必须由你确认后才写入影片资料。
- 播放始终在本机进行，依次尝试 IINA、VLC 和 macOS 系统默认播放器；断网不会阻止已扫描文件播放。
- macOS 会要求选择文件夹的访问权限。移动磁盘未连接或文件被移动时，请重新连接存储卷或使用“重新定位文件”。

## 数据

本测试包已配置 CineBar 开发者维护的 TMDB 与 OMDb 数据服务。预览使用者无需
域名、Cloudflare、API Key、数据库、任何社区账号或项目部署。社区评分和品牌
分享服务同样已经配置，可直接使用。商业化前仍须按照各数据源条款确认授权。

客户端使用 `api.cinebar.cc`、`community.cinebar.cc` 和
`share.cinebar.cc`，不依赖旧测试服务域名。用户无需代理或 VPN。网络暂时异常时，
电影与电视剧首页会优先显示上次成功加载的真实数据；没有缓存时才显示演示内容。
当前没有香港备用服务器，单一网络实测不能代表所有中国大陆运营商。

此包使用临时签名且未经 Apple 公证，第一次打开时仍需按安装说明完成 macOS
安全确认。经验证的测试包会以预发布形式通过 GitHub Releases 交付。

## 更新

Build 23 当前通过 [GitHub Releases](https://github.com/leeugm-create/CineBar/releases) 手动下载和安装；
待已签名的 Build 23 appcast 与归档发布后，才可在 CineBar 的“设置”→“更新”中安装。
Build 16 需要先通过
[GitHub Releases](https://github.com/leeugm-create/CineBar/releases) 手动安装一次
Sparkle 版本（Build 17 或更新版本）。完成这次迁移后，后续版本可以
在 CineBar 的“设置”→“更新”中检查、下载并安装。每个更新包都会由 CineBar 内置的
EdDSA 公钥验证；签名不匹配的包不会安装。

各版本的简短更新说明保存在 `ReleaseNotes/`，并随安装包一并保留。

测试构建仍未经过 Apple 公证。若不希望启动时自动检查，可在“设置”→“更新”关闭
“启动时自动检查更新”，并可随时使用“立即检查”手动检查。

Rotten Tomatoes Popcornmeter 观众分未抓取、未内置。接入该数据需要
Rotten Tomatoes 的正式数据授权。

This product uses the TMDB API but is not endorsed or certified by TMDB.

客户端更新检查和品牌分享可共用 `../CineBarShare` Cloudflare Worker。
