CineBar 0.9.0-test.1 · Build 127

【修复】电视直播浮窗无法返回（Build 126 反馈）
- 独立播放窗口的「关闭播放」按钮此前只在全屏模式显示，浮窗（直播/正片）模式下没有返回入口，点「浮窗」后主面板隐藏即被困在播放界面
- 修复：浮窗模式新增「全屏」与「关闭播放」按钮，任何模式均可显式返回主面板（Esc 与窗口红点关闭仍有效）

【网页】播放页 /watch 升级为 zip0 完整布局
- 双栏布局：左主栏（播放器 → NOW PLAYING 摘要 → 选集 → 影片详情 → 相关影视推荐），右侧 300px 线路面板
- 右侧「播放来源」线路列表：同片名多源聚合（量子/暴风/最大/急速/非凡），每条显示「线路 N + 质量标签 + 探测延迟 ms」，当前线路高亮，点击整页切换线路（zip0 同款）
- 播放器下方选集：全集按钮网格（电影 1 集也显示，与 zip0 一致），点集即播并同步 URL episode 参数
- 底部「相关影视推荐」：同分类热门卡片（海报 + 状态标签 + 标题），点击直达对应源播放页
- 影片详情区：海报 + 年份/类型/质量标签 + 简介（剥离源站 HTML 标签）
- URL 双兼容：/watch?source=&id=&episode=（精确直达）与 /watch?title=（搜索入口，首页卡片沿用）

【说明】本轮为 0.9 测试版，未公证、未上架 Mac App Store；网页端改动已同步部署 cinebar.cc
