CineBar 测试版安装说明
版本：0.8.3-test.15
适用于：macOS 13 Ventura 及以上

这是功能验证用测试版，不是正式发行版。应用仅使用临时（ad-hoc）代码签名，未经 Apple 公证、未上架 App Store。请只使用开发者提供的 CineBar 安装包。

安装步骤
--------
1. 如果旧版 CineBar 正在运行，点击菜单栏图标，再点击左下角"退出"。
2. 双击下载的 ZIP 解压，文件夹里是 CineBar.app 和本说明。
3. 把 CineBar.app 拖进"应用程序"文件夹（系统询问是否替换时，确认旧版已退出后选"替换"）。

第一次打开
--------
1. 在"应用程序"中找到 CineBar。
2. 按住 Control 键点击 CineBar，选择"打开"。
3. 出现"无法验证开发者"提示时，再选择"打开"。
4. 启动后，在屏幕顶部菜单栏寻找 CineBar 图标。

若没有"打开"按钮：
进入"系统设置"→"隐私与安全性"，向下找到被阻止的提示，点击"仍要打开"，验证密码或 Touch ID。不要关闭整个 macOS 安全保护功能。

更新
--------
新版本可在 CineBar 的更新检查中下载并安装，也可直接到官网 https://cinebar.cc 下载最新安装包。每个更新包都会用内置公钥校验签名，签名不匹配的包不会安装。
