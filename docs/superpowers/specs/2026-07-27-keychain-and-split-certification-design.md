# CineBar 0.8.1-test.2 修复与分享优化设计

**日期：** 2026-07-27
**目标版本：** 0.8.1-test.2（Build 14）
**状态：** 用户已确认

## 目标

移除首次启动时不必要的 macOS 钥匙串密码提示；将地区官方分级与 CineBar
统一年龄分级拆成两个并列、排版一致的独立信息框；增加玻璃背景不透明度设置；
缩短电影与电视剧分享链接，并让系统分享消息直接包含可识别的作品信息。

## 1. 匿名安装身份

### 根因

匿名评分安装编号目前使用 Security framework 保存到登录钥匙串。测试包采用
临时签名，每次重新构建可能具有不同的代码签名身份；读取旧钥匙串项目时，
macOS 会要求用户输入登录钥匙串密码。

### 修复

- 匿名安装编号改存到 CineBar 自己的 `UserDefaults`。
- 键名固定为 `communityAnonymousInstallID`。
- 第一次需要评分身份时生成 UUID 并保存，以后复用同一值。
- 完全停止调用 `SecItemCopyMatching` 和 `SecItemAdd`。
- 不读取、不迁移旧钥匙串项目，避免迁移过程再次触发密码框。
- 已存在的钥匙串项目可以保留；新版不会访问它。
- 更换电脑、删除 CineBar 偏好设置或重装系统后可能产生新的匿名身份，这是
  无账号方案的既有边界。

匿名 UUID 只用于生成服务端散列身份，不是用户密码，也不包含个人资料，因此
不需要钥匙串级别的保护。

## 2. 双分级框

电影与电视剧详情页共用同一个双分级组件，包含两个并列信息框。

### 地区分级框

- 上方小字显示地区名称或地区代码，例如“美国”或 `US`。
- 下方显示大号、加粗、红色的官方分级，例如 `PG-13`、`R`。
- 没有数据时，上方显示“地区分级”，下方显示“未分级”。

### CineBar 分级框

- 排版、尺寸、圆角、内边距和边框结构与地区分级框一致。
- 上方小字显示 `CineBar 分级`。
- 下方大号、加粗显示统一年龄提示，例如 `13+`、`18+`、`家长指导`。
- 使用橙色强调，避免与地区官方分级混淆。
- 没有可转换数据时显示“未分级”。

### 不变内容

- TMDB、IMDb、烂番茄、Metacritic 与社区用户 CineBar 分数仍位于“多重评分”。
- “我的评分”仍遵守一次提交、不可修改或删除的规则。
- 双分级框只表示内容年龄分级，不表示用户对影片质量的评分。

## 3. 玻璃背景不透明度

在“设置 → 外观”增加“玻璃背景不透明度”：

- 使用滑块调节，范围为 50%–100%，默认值为 85%。
- 调整时主菜单栏面板即时更新，不需要关闭或重新打开 CineBar。
- 设置写入 `UserDefaults`，下次启动继续使用。
- 提供“恢复默认”操作，将数值恢复为 85%。
- 只调整玻璃背景层或背景衬色层，不改变文字、图标、海报、按钮和预告片的
  不透明度。
- 设置仅作用于 CineBar 主菜单栏面板，不改变独立设置窗口。
- 浅色、深色和跟随系统三种外观均使用同一个用户数值，并根据当前外观选择合适
  的背景颜色，避免纯黑桌面下文字对比度不足。
- 不使用整个窗口的 `alphaValue`，防止内容与交互控件一起变淡。

## 4. 短链接与系统分享

### 短链接

现有分享链接把片名、年份、评分、海报和简介放在查询参数中，导致微信消息里出现
很长的字符。本版改为只在链接中保留作品类型与 TMDB 编号：

- 电影：`https://<分享域名>/m/<TMDB ID>`
- 电视剧：`https://<分享域名>/t/<TMDB ID>`

分享 Worker 根据类型和编号从已配置的影片资料源读取分享页所需的片名、年份、
评分、海报与简介。短链接是确定性的永久链接，不设置有效期，也不要求用户登录，
不为每次分享创建数据库记录。

Worker 的影片资料凭据作为 Cloudflare Secret 配置，不写入分享网址、网页源码或
安装包。资料临时不可用时仍返回带 CineBar 品牌和作品编号的可打开页面，而不是
空白页或 404。

### 系统分享消息

系统分享不再只传一个 URL，而是同时传递格式化文字和短链接。电影示例：

```text
🎬《沙丘2》（2024）
⭐ TMDB 8.1｜CineBar 8.6
在 CineBar 查看简介、演员阵容与观看信息：
https://<分享域名>/m/693134
```

电视剧使用电视图标，并把提示改为“查看剧集资料与播出信息”。默认包含：

- 电影或电视剧名称；
- 上映或首播年份；
- TMDB 评分；
- CineBar 社区评分（已有有效评分时才显示）；
- 简短查看提示；
- 对应的短链接。

不把完整简介加入聊天消息，避免微信、微博等平台中的分享文字过长。分享网页继续
输出 Open Graph 标题、简介和海报；平台支持网页预览时可生成影片卡片，但文字本身
不依赖卡片也能让接收者识别作品。

### CineBar 下载入口

- 分享网页底部预留 CineBar 下载区域。
- 配置有效下载地址后显示“下载 CineBar for macOS”按钮。
- 尚未配置下载地址时隐藏整个下载按钮，不显示空链接、禁用按钮或占位网址。
- 下载地址由分享 Worker 的部署配置提供，后续可指向官网、Cloudflare 下载页或
  正式安装包。

## 5. 测试与验收

- 新安装启动和进入电影、电视剧详情时不出现钥匙串密码框。
- 源码不再包含匿名身份的 Security framework 钥匙串读写调用。
- 同一次安装多次启动取得相同匿名 UUID。
- 地区分级与 CineBar 分级显示为两个独立框。
- 两个框排版一致，地区值红色，CineBar 值橙色。
- 电影和电视剧详情使用相同组件。
- 背景不透明度可在 50%–100% 调整、即时生效并在重启后保持。
- 调整背景不透明度时文字、海报、按钮和其他前景内容保持完全不透明。
- 系统分享电影与电视剧时均包含作品名称、年份、可用评分、提示语和短链接。
- 电影短链接只使用 `/m/<ID>`，电视剧短链接只使用 `/t/<ID>`，没有影片资料查询
  参数。
- 短链接可重复打开；资料源暂时失败时显示 CineBar 后备页面。
- 分享页配置下载地址时显示下载按钮，未配置时不显示按钮。
- 分享页的标题、简介、海报和短链接 Open Graph 信息正确。
- Swift 回归测试、类型检查、社区 Worker 测试全部通过。
- 分享 Worker 路由、资料后备和下载按钮状态测试全部通过。
- 重新构建 Intel 与 Apple 芯片通用包。
- 安装说明更新为 0.8.1-test.2（Build 14），并明确新版不需要钥匙串密码。
