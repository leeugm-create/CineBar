# CineBar 中国区自定义域名与网络容错设计

**日期：** 2026-07-27  
**目标：** 解决 CineBar 0.8.2-test.1 在中国大陆无代理网络中访问
`workers.dev` 时出现 DNS、TLS 或连接失败的问题，并为未来香港备用入口预留
结构。

## 1. 范围

本轮只处理：

- 注册并接入 `cinebar.cc`；
- 将三个公开 Cloudflare Worker 从客户端可见的 `workers.dev` 地址迁移到
  CineBar 自定义域名；
- 增加健康检查、网络重试、错误呈现和真实数据缓存策略；
- 完成中国大陆多运营商网络验证；
- 重新生成不包含 `workers.dev` 地址的测试安装包。

以下需求明确延期，不混入本轮：

- 即将上映列表显示上映日期；
- 修改系统分享名称；
- 分享网页增加主演信息；
- 分享网页增加 GitHub Releases 下载入口。

## 2. 已确认的问题

CineBar 0.8.2-test.1 将数据代理地址固定为：

`https://cinebar-data.leeugm.workers.dev`

在当前中国大陆网络环境中，直接 DNS 查询会将多个 `workers.dev` 子域名解析到
不相关或不可连接的地址。直接连接失败，而经过本机系统代理后相同 Worker 可以
返回 HTTP 200。因此问题发生在用户设备到 `workers.dev` 的公开网络入口，而
不是 TMDB、OMDb、Worker 程序、Cloudflare Secret 或安装包签名。

自定义域名能够避开针对 `workers.dev` 后缀的入口问题，但普通 Cloudflare
全球网络仍不等同于 Cloudflare 中国网络。本设计不承诺在中国大陆所有网络中
百分之百可用。

## 3. 域名与费用

注册商使用现有 Cloudflare 账户中的 Cloudflare Registrar。

- 域名：`cinebar.cc`
- 2026-07-27 账户实时报价：首年 8.00 美元
- 当前续费报价：每年 8.00 美元
- 域名注册完成后不可退款
- 购买前必须由用户确认并完成 Cloudflare 默认联系人、付款方式以及适用协议
- 开启自动续费，避免后台服务因域名到期同时失效

## 4. 服务边界

### 4.1 数据服务

`api.cinebar.cc` 指向现有 `cinebar-data` Worker。

职责：

- 代理 TMDB 影片、电视剧、演员、图片配置等允许路径；
- 代理 OMDb IMDb、Rotten Tomatoes、Metacritic 多重评分；
- 保存 `TMDB_TOKEN` 与 `OMDB_API_KEY` Cloudflare Secrets；
- 提供 `GET /health`。

### 4.2 社区评分

`community.cinebar.cc` 指向现有 `cinebar-community` Worker。

职责：

- 读取电影和电视剧的 CineBar 公共评分；
- 接收每台设备每部作品一次的匿名评分；
- 连接现有 D1 数据库；
- 提供 `GET /health`。

### 4.3 分享与更新

`share.cinebar.cc` 指向现有 `cinebar-share-test` Worker。

职责：

- 展示电影和电视剧品牌分享页；
- 提供更新清单；
- 以后承载下载入口；
- 提供 `GET /health`。

### 4.4 根域名

`cinebar.cc` 第一阶段显示一个轻量 CineBar 品牌页。该页面只说明产品名称和
测试状态，不在本轮增加完整官网、下载中心或其他产品功能。

### 4.5 香港备用入口

预留 `api-hk.cinebar.cc` 名称，但第一阶段不创建服务器、不添加无效 DNS
记录，也不让客户端访问这个地址，因此不会增加费用或制造额外超时。

以后实际部署香港服务后，才把它加入客户端备用端点列表。三个主服务保持独立，
一个服务故障不影响另外两个服务。

## 5. DNS、证书与路由

- 每个主子域名使用 Cloudflare Worker Custom Domain；
- Cloudflare 自动创建 DNS 记录并签发对应 HTTPS 证书；
- 客户端只信任标准系统证书链，不绕过 TLS，不允许自签名证书；
- 正式客户端与安装说明中不再包含任何 `workers.dev` 地址；
- `workers.dev` 部署可暂时保留用于开发维护，但不作为客户端备用入口；
- 不通过修改本机 DNS、关闭 ATS、忽略证书验证或要求用户使用代理来规避问题。

## 6. 客户端端点与数据流

安装包写入：

- 数据：`https://api.cinebar.cc`
- 社区：`https://community.cinebar.cc`
- 分享：`https://share.cinebar.cc`

每个客户端模块只读取自己的端点配置，不能自动把数据请求发送到社区或分享
域名。API Token 和 Key 继续只存在 Cloudflare Secret 中。

请求数据流：

1. 客户端向对应 `cinebar.cc` 子域名发送 HTTPS 请求；
2. Cloudflare 根据 Custom Domain 调用对应 Worker；
3. 数据 Worker 使用服务器 Secret 请求 TMDB 或 OMDb；
4. 社区 Worker 访问 D1；
5. Worker 返回结果，客户端更新界面并保存适合离线展示的最后成功数据。

## 7. 网络错误处理

### 7.1 可重试错误

以下错误允许自动重试：

- DNS 解析失败；
- TLS 握手失败；
- 无法连接；
- 连接中断；
- 请求超时；
- HTTP 500–599。

同一主入口短暂等待后最多重试一次，避免无限循环和请求风暴。

### 7.2 不重试错误

HTTP 400、401、403、404 等请求或权限错误不自动切换入口。客户端显示经过翻译
的服务提示，并记录不含密钥、设备身份或用户数据的诊断代码。

### 7.3 备用入口

第一阶段备用入口列表为空。以后 `api-hk.cinebar.cc` 实际上线后，主入口在
一次重试后仍发生可重试错误，客户端才切换备用入口。备用入口成功后只在当前
会话内优先使用，不永久篡改应用配置。

### 7.4 降级显示

- 网络失败时优先显示最后一次成功加载的真实数据；
- 明确提示“网络不稳定，正在显示上次更新内容”；
- 只有新安装且从未成功加载真实数据时才显示演示数据；
- 不直接向普通用户展示 macOS 原始 TLS 错误文字；
- 设置页提供可复制的非敏感诊断摘要，包括服务名、错误类别、时间与应用版本。

## 8. 健康检查

三个 Worker 分别提供：

- `https://api.cinebar.cc/health`
- `https://community.cinebar.cc/health`
- `https://share.cinebar.cc/health`

响应只包含：

- `ok`；
- 服务名称；
- 部署版本；
- UTC 时间。

健康检查不得包含 Secret、D1 内容、设备标识、账号信息或上游完整响应。
健康检查使用短缓存或不缓存，且不调用 TMDB、OMDb 或 D1，以便准确区分入口
故障与上游故障。

## 9. 验证要求

### 9.1 自动化

- 为三个 `/health` 路由增加 Worker 单元测试；
- 为客户端端点选择、可重试错误判断和备用切换增加 Swift 回归测试；
- 验证 HTTP 4xx 不触发备用切换；
- 验证最多重试一次；
- 验证错误摘要不包含 URL 查询密钥；
- 扫描源码、应用包和压缩包，不得出现真实 API Secret；
- 扫描正式客户端配置和安装文档，不得出现 `workers.dev`。

### 9.2 线上服务

逐项验证：

- 三个自定义域名证书与主机名匹配；
- 三个 `/health` 返回 HTTP 200；
- TMDB 影片详情正常；
- OMDb 多重评分正常；
- 社区评分可读取并完成一次测试提交；
- 分享页面和更新清单正常；
- 无效 OMDb 参数仍被拒绝；
- 公开 URL、错误和缓存键不包含 Secret。

### 9.3 中国大陆网络

至少覆盖：

- 中国移动；
- 中国联通；
- 中国电信。

测试必须关闭代理和 VPN。每种网络完成连续请求、冷启动、详情页刷新、评分读取
和分享页打开测试。测试期间不得出现 DNS 或 TLS 错误。若任一运营商仍稳定复现
入口错误，本轮不得标记为中国区可发布，需转入香港备用入口方案。

## 10. 迁移顺序

1. 在 Cloudflare 下单前再次确认 `cinebar.cc` 实时可注册且费用仍为 8 美元；
2. 用户完成默认联系人、付款信息和最终购买；
3. 为根域名和三个 Worker 配置 Custom Domain；
4. 等待 DNS 与证书状态全部生效；
5. 部署健康检查并验证线上服务；
6. 完成无代理及三运营商测试；
7. 修改客户端端点、重试与降级逻辑；
8. 运行完整自动化测试；
9. 构建、临时签名并检查通用安装包；
10. 只在所有验收项通过后交付新的中国区测试版。

迁移期间不删除原 `workers.dev` 部署，便于回滚。回滚只恢复 Worker 路由或客户端
测试配置，不关闭证书验证、不回退到用户自行填写密钥。

## 11. 成功标准

- 用户安装后无需 API Key、Cloudflare、D1、社区账号、代理或 VPN；
- 中国大陆无代理测试不再出现截图中的 TLS 错误；
- 三个生产入口均使用 `cinebar.cc`；
- 真实数据失败时有缓存降级和可理解的提示；
- 第一阶段新增固定费用只有 `cinebar.cc` 每年 8 美元；
- 后续可在不更换主域名的情况下增加香港备用服务。
