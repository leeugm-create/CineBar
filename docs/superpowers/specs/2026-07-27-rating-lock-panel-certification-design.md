# CineBar 一次性评分、跨屏定位与分级展示设计

**日期：** 2026-07-27  
**状态：** 已获用户确认  
**发布通道：** 仅测试分支，不作为正式版

## 目标

修复 CineBar 匿名评分、菜单栏窗口跨屏定位、内容分级展示和评分滑块交互问题，并明确分享服务的部署方法。

## 已确认规则

- 不增加账号、注册或登录系统。
- 同一份 CineBar 安装使用保存在本机钥匙串中的匿名设备标识。
- 同一匿名设备对同一部电影或电视剧只能评分一次。
- 评分范围仍为 0–10 分，步进为 0.5 分。
- 评分一旦成功提交，不可修改、不可删除。
- 换电脑、删除本机身份数据或重装系统后可能被识别为新设备，这是无账号方案的边界。
- 本次成果只进入测试分支，不覆盖 `main`，不创建正式 Release。

## 一次性评分

客户端在 `my_score` 为空时显示评分编辑器；有值时隐藏编辑器，只在多重评分中显示结果。编辑器必须提示“每部影片只能评分一次，提交后不可修改或删除，请谨慎评分”，提交前还需要二次确认。

服务端将覆盖式写入改为仅插入。重复的 `(media_type, media_id, device_hash)` 返回 HTTP `409 Conflict`；删除接口返回 `405 Method Not Allowed`。数据库唯一约束继续作为并发情况下的最终防线。

## 评分滑块与窗口拖动

使用 macOS 原生 `NSSlider` 包装成 SwiftUI 组件，显示 0–10 分的 21 个半分刻度。扩大轨道和点击区域，并让滑块视图明确拒绝把鼠标按下用于移动窗口。

## 多显示器定位

以菜单栏 `NSStatusItem` 按钮所属窗口的屏幕为第一判断依据，使用按钮屏幕坐标作为横向锚点。每次点击图标重新限制面板尺寸并定位；只有无法取得按钮屏幕时才回退到鼠标所在屏幕和主屏幕。

## 电影与电视剧分级

国家或地区使用较小的次要文字；原始分级使用明显放大的红色粗体。电影和电视剧详情共用同一组件，无数据时不伪造分级。

## 分享服务部署

分享页继续使用独立的 Cloudflare Worker：

1. 从 `CineBarShare` 部署 `cinebar-share`。
2. 获取 `https://cinebar-share.<子域>.workers.dev` 地址。
3. 将地址写入 `CineBarShareURL`。
4. 重新构建 CineBar。
5. 验证电影和电视剧分享页的标题、海报、简介、评分和 CineBar 品牌。

- 常见问题

安装说明必须以普通用户可以逐步照做为标准，不能只提供开发命令。

## 验证标准

- 电影和电视剧首次评分成功，提交后编辑器立即消失。
- 第二次服务器请求返回 `409`，原分数不变。
- `DELETE` 不再删除评分。
- 可移动窗口模式下滑块顺畅拖动且窗口不移动。
- 在两个不同尺寸显示器上点击图标，面板出现在对应屏幕且不溢出。
- 分级国家文字较小，分级值明显放大、加粗、标红。
- 分享 Worker 独立可访问且 CineBar 使用正确域名。
- 测试安装包内含完整安装说明。
